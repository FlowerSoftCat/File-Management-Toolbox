# FileToolkit — 全能文件处理工具箱

一个基于 Tkinter 的 Windows 桌面工具，集成压缩包后缀修复、视频去声、文件自动分类、批量删除和视频字幕重命名功能。

## 功能概览

- 📁 **压缩包后缀修复**
  - 自动检测压缩文件后缀是否正确
  - 支持 `rar`, `zip`, `7z`, `tar`, `gz`, `bz2`, `xz`, `iso`, `cab`, `arj`, `lzh`, `z`, `tgz`, `zst`, `lz4`, `lzma`
  - 通过文件魔数识别真实格式，建议纠正后缀

- 🎵 **视频批量去声**
  - 处理目录下所有视频文件
  - 调用 FFmpeg 去除音轨并生成 `_去声` 版本
  - 支持 `mp4`, `avi`, `mkv`, `mov`, `flv`, `wmv`, `mpeg`, `mpg`, `webm`

- 📂 **文件自动分类**
  - 按文件名核心部分自动分组
  - 去掉末尾数字后缀（如 `xxx_1`, `xxx_2`）后归类到同名文件夹
  - 清理单文件文件夹并将文件移动到上级目录

- 🗑️ **批量删除指定文件**
  - 关键字匹配或精确文件名匹配
  - 支持递归扫描子目录
  - 提供删除预览与确认机制

- 🎬 **视频字幕批量重命名**
  - 扫描视频与字幕文件
  - 支持“视频名 → 字幕名”或“字幕名 → 视频名”方向重命名
  - 当前版本为示例逻辑，需按项目需求完善匹配算法

## 运行环境

- Windows
- Python 3.7+
- Tkinter（Python 默认通常已包含）
- FFmpeg（用于视频去声功能，可选，但推荐安装并添加到系统 PATH）

## 使用说明

1. 运行 `FileToolkit.py`：

   ```bash
   python FileToolkit.py
   ```

2. 启动后，程序默认窗口为最大化显示

3. 各功能页面通过顶部标签页切换

4. 各页面需要先选择目录，然后执行对应操作

## 各模块使用说明

### 1. 压缩包后缀修复

- 点击“浏览”选择目录
- 点击“扫描”分析目录下所有压缩文件
- 程序会检测后缀是否符合文件真实格式并给出修复建议

### 2. 视频批量去声

- 点击“浏览”选择视频所在目录
- 程序会列出目录内支持的视频文件
- 点击“开始去声”生成 `*_去声` 版本

### 3. 文件自动分类

- 点击“浏览”选择目标文件夹
- 程序会根据文件名核心部分对相似文件进行分组
- 自动创建同名文件夹并移动文件

### 4. 批量删除指定文件

- 选择目录后输入关键字或文件名
- 选择“关键字匹配”或“精确匹配”
- 点击“扫描”查看待删除文件列表
- 确认后执行删除

### 5. 视频字幕批量重命名

- 选择包含视频和字幕文件的目录
- 点击“扫描文件”读取视频与字幕文件
- 选择重命名方向并执行重命名
- 说明：当前逻辑为简单示例，实际匹配规则可继续增强

## 注意事项

- 若使用视频去声功能，请先安装 FFmpeg 并将其执行文件路径加入系统 PATH
- 当前程序仅适合文件名简单规则的自动分类和字幕重命名示例
- 运行时请确保目录内文件无占用权限问题
